Replay of recorded KnowWhen-R test runs. Pick a model and a target share of questions answered to see wrong and correct answer rates on all 3,968 test questions, then open random questions to see what the closed book answer, the retrieved answer and the probes said. Nothing is generated live: every answer and score comes from the saved runs, built by `scripts/build_static_demo.py`.

Code and report: https://github.com/Optimus2007/knowwhen-r. Probes: `kungfupanda12/knowwhen-r-probes`. Traces: `kungfupanda12/knowwhen-r-traces`.
